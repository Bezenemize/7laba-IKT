## 1. DOM-дерево

DOM-дерево (Document Object Model) — это программное представление HTML-документа в виде древовидной структуры, где каждый тег, атрибут и текст является объектом. Браузер создает это дерево при загрузке страницы, чтобы JavaScript мог читать и динамически изменять её содержимое, структуру и стили.

Является ли хорошей практикой дёргать DOM?

Думаю нет, так как каждое изменение может заставить браузер пересчитывать стили и перерисовывать страницу, что снижает производительность, особенно на мобильных устройствах.

## 2. Антипаттерн console.log()

Оставление множества операций `console.log()` в продакшен-коде — это распространенный антипаттерн, которого следует избегать.

Почему это плохо?
*   Загрязнение вывода: В консоли разработчика накапливается много лишней информации, что мешает отладке реальных проблем.
*   Утечка данных: В логах могут случайно оказаться конфиденциальные данные пользователей (пароли, токены, персональная информация).
*   Влияние на производительность: В больших объемах вывод в консоль может незначительно, но замедлять работу приложения.
